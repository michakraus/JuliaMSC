## Long Description (1350 chars with spaces)

Julia is a modern programming language tailor-made for scientific computing. It combines high-level code with high-performance execution. Its unique set of features and ecosystem facilitate the development of robust and flexible research code like no other programming language. This book explains how to utilize these virtues to develop better scientific software.

You will learn about essential concepts such as dynamical typing, multiple dispatch and related design patterns. Differences to class-based object-oriented languages will be pointed out in order to ease the transition from these languages.
You will study modern research software engineering practices that facilitate code which is at the same time robust and maintainable, performant and flexible, reusable and extensible.
The book also provides an overview of useful libraries that solve typical tasks such as reading and writing data, solving equations, automatic differentiation, and basic machine learning tasks.
Finally you will explore parallel programming with different paradigms such as shared memory parallelism with threads, distributed memory parallelism with MPI, and GPU programming.

By the end of the book you will be able to develop scientific software with Julia, think in a Julian way, apply research software engineering techniques, and write parallel programs.

## Audience (600 characters with spaces)

The book is intended for all scientists that develop research software. While the focus lies on software that implements numerical algorithms for the solution of differential equations, researchers from other areas such as data science and machine learning will still profit if their use cases go beyond merely running existing code.
Preferably readers should have prior exposure to the Julia programming language. However, programmers experienced in another language like Python or C++ should be able to follow along after reviewing the introductory chapter on important elements of the language.

## Author Bio (750 chars with spaces)

Michael Kraus leads a research group at the Max Planck Institute for Plasma Physics. His research focuses on the development of novel numerical algorithms that combine ideas from differential geometry, classical numerical analysis, scientific machine learning and reduced complexity modelling. He has over 20 years of experience in software development inside and outside of academia. Since 2015 Julia is his preferred programming language for scientific software development. Michael is the main author of numerous Julia packages such as GeometricIntegrators.jl, GeometricMachineLearning.jl or ReducedComplexityModeling.jl. Since 2020 he creates and delivers training courses for scientific computing in Julia and research software engineering.
